## How to work on it

- `git pull --rebase`, then build, validate, leak scan, tests, role-scope and abp-check through `scripts/release.sh` (it also refuses during a hold or with uncommitted changes). CI repeats the gates, deploys and tags v0.1.N.
- Pages: `src/<page>/index.html` with the markers `<!--HEAD-->`, `<!--HEADER-->`, `<!--FOOTER-->`; the layout, the disclaimer, the link previews and the Markdown twins come from `scripts/lib.mjs` and `scripts/layout.mjs`. Data: `src/assets/js/data.js` (loader, provenance, age lines, failure messages), `map.js` (the hex map built in the browser from IPMA's municipality points), `codes.js` (IPMA's code tables, with sources). Share cards: `node scripts/cards.mjs` (needs Playwright). Behind the scenes is generated by `scripts/behind.mjs` from `team/` and git log.
