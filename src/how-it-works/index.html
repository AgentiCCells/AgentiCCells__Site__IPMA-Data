How it works

The data takes four steps to reach you. Only the last one happens here, and it happens in your browser.

The steps

  1. IPMA (Instituto Português do Mar e da Atmosfera) publishes warnings, forecasts, observations, fire risk, sea and UV data on its open data service. IPMA is the source of every weather figure on this site.
  2. PrompTugal.news's collectors read each IPMA source on a schedule and keep the latest copy, plus a list of past reads (reads.json) and a source card (card.json) with provenance and terms.
  3. data.promptugal.news serves those files at https://data.promptugal.news/api/v1/<source>/. Every file is a plain GET with no key, and any website may read it from a browser. The catalogue is at api/v1/index.json.
  4. This page is static HTML, CSS and a small script, all served from ipma-data.agenticcells.site. When you open a page, the script fetches latest.json, card.json and reads.json for that source, finds the records and draws them. It shows the time PrompTugal.news read each file, and says so when a file is missing, unreadable or older than expected.

What this means

  • The figures can be behind IPMA by as long as it takes the collectors to read the next copy. Each page shows that read time.
  • No server of ours stores or changes the data. Nothing about you is collected: no cookies, no analytics, no fonts or scripts from other hosts.
  • When a file cannot be read or a field cannot be recognised, the page says so and shows the records as a plain table instead of guessing.
  • The thresholds for calling a file stale are this site's choice, not IPMA's: 3 hours for warnings and observations, 24 hours for forecasts and sea, 36 hours for fire risk and UV.

Who made it
