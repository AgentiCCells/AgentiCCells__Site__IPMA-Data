Designs

Six designs: the main design and five others, each drawing the same IPMA data. The main design is the whole site; the five others are full home pages, each in its own style, from the round 1 design proposal.

  • The main design The whole site: a map, charts and tables on a calm page, in light or dark. Palette: #f7f5f0, #ffffff, #1d2329, #5b6670, #0b5c7a. Type sample: Lisboa 13 to 19°
  • Broadsheet A newspaper weather page: a headline from the data, the map large, dense tables. Palette: #f4f1ea, #161616, #8a1c1c, #d8d2c4, #5a5a5a. Type sample: Lisboa 13 to 19°
  • Chart room Sea first: coastal wave ranges lead, with rough-sea warnings and wind beside them. Palette: #f3f0e4, #dbe7ec, #13324b, #9db4c0, #2f6f9f. Type sample: Lisboa 13 to 19°
  • Night desk A dark operations board: a tile per source with its status light and read age. Palette: #0d1117, #161b22, #e6edf3, #8b949e, #5fb3d3. Type sample: Lisboa 13 to 19°
  • Almanac A printed almanac page in tables, readable in greyscale, on one A4 sheet. Palette: #faf6ec, #222222, #9a6a12, #e9e1cc, #6b6250. Type sample: Lisboa 13 to 19°
  • Glance Phone first: one sentence per place, a small map, every source's age at the foot. Palette: #ffffff, #111111, #0b5c7a, #f2f4f5, #5b6670. Type sample: Lisboa 13 to 19°

Every design reads the same live files; only the way they are drawn differs.

In every design: the disclaimer, IPMA named as the source with the read time and terms beside every chart, a plain message when a file is missing, stale or slow, and warning levels written as words beside hatched swatches, so a red warning looks red everywhere. The previews above are drawings of each layout, not data. The list is also at designs.json.
