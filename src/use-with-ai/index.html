Use with AI

The charts on this site are drawn in your browser, so an AI assistant reading the pages sees little data. Point it at the files instead: they are public, need no key, and carry their own provenance.

Files to give an assistant

  • llms.txt for this site: what it is, its pages and the files behind them.
  • data.promptugal.news/llms.txt: the data site's own guide.
  • The catalogue, api/v1/index.json, the OpenAPI description and the contract.
  • For each source (ipma-warnings, ipma-city-forecasts, ipma-observations, ipma-fire-risk, ipma-sea, ipma-uv, meteoalarm-pt): https://data.promptugal.news/api/v1/<source>/latest.json, plus reads.json, card.json and openapi.json in the same folder.

A prompt you can start from

Read https://data.promptugal.news/llms.txt and
https://data.promptugal.news/api/v1/ipma-warnings/card.json, then
https://data.promptugal.news/api/v1/ipma-warnings/latest.json.
List the areas with a yellow, orange or red warning, with the start
and end times. Give the time the file was read, name IPMA as the
source, and say plainly if the file looks stale or a field is missing.
Do not present the answer as an official warning.

This is a suggestion, not a tested recipe: check what the assistant says against ipma.pt.

Rules that come with the data

  • IPMA's terms, as data.promptugal.news gives them: free to copy and use for personal or public use if the use has no profit-making or offensive purpose; always name IPMA as the source.
  • Give the read time with any figure. A copy can be behind IPMA.
  • Do not present an answer as a warning. For warnings and safety, people should follow IPMA and ANEPC.
