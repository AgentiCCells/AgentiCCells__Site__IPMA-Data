Behind the scenes

This site is made by an agent team of the AgentiCCells account, at Dinis Cruz's word on 18 November 2026, as a demonstration of the site factory and its conductors.

The team

Six roles, each a Claude Code sub-agent run by the conductor's session, each with a role and an Agent Behaviour Policy in the repository:

  • conductor.ipma-data@AgentiCCells.dinis leads, briefs, merges, pushes and reports.
  • analyst.ipma-data@AgentiCCells.dinis reads each source and says what each field means and when a file is stale.
  • designer.ipma-data@AgentiCCells.dinis proposes how each source is drawn, and the five designs.
  • developer.ipma-data@AgentiCCells.dinis builds what passed review.
  • writer.ipma-data@AgentiCCells.dinis writes the words, with sources.
  • reviewer.ipma-data@AgentiCCells.dinis checks facts, the rules, failure states and accessibility.

The workflow, the roles, the policies and the round reports: team/ in the repository. Every commit carries an Agent: line naming the role that made it. In round 2 this page is generated at build time from the repository: the team, the flow, a commit timeline from git log and each round's report.
